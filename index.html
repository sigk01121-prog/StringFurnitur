1949년부터 우리는 전 세계 사람들의 일상을 더욱 풍요롭게 하는, 시대를 초월하면서도 실용적인 디자인을 선보이는데 매진해 왔습니다. 세심하게 제작된 유연한 가구와 수납 솔루션은 스칸디나비아 특유의 단순미와 스타일이 완벽하게 조화를 이룹니다.

아이코닉한 String System부터 String Pocket, Museum Pira, Relief, Center Center와 같은 새로운 컬렉션까지, 당신의 취향과 라이프스타일에 맞는 공간을 완성할 다양한 영감을 만나보세요. String Furniture의 디자인 클래식인 String Shelf를 비롯한 다양한 제품은 주방, 침실, 거실 워크스페이스등 어떤 공간에도 스타일과 실용성을 더해줍니다. 나만의 공간에 어울리는 디자인을 발견하고, String Furnitur와 함께 당신의 라이프스타일을 완성해보세요.
